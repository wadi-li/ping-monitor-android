# Пинг-монитор 1.0.0

Нативная Android-версия монитора доступности выбранных адресов. Вместо HTML/WebView используются фоновый foreground service, HTTP/HTTPS, TCP и системный ICMP ping.

## Что включено

- От 1 до 50 адресов, сохранение полного URL с протоколом, портом и путём.
- Перестановка адресов кнопками «Выше» / «Ниже» с сохранением порядка.
- Индивидуальный переключатель «Не опрашивать» / «Опрашивать» без удаления адреса и прежней статистики.
- Зелёный, жёлтый и красный статусы в интерфейсе и раскрытом уведомлении.
- Общий монохромный значок-кружок в строке состояния с галочкой, `!` или крестом.
- Настройки интервала, таймаута, задержки и порога последовательных ошибок.
- Светлая и тёмная темы, графики, PNG, импорт TXT/CSV и отчёт CSV `;` с UTF-8 BOM.
- Отсутствие рекламы, аналитики, CDN и внешних runtime-библиотек.

## Установка

Установите `ping-monitor-1.0.0.apk`, откройте приложение и разрешите уведомления. Добавьте адреса, настройте порядок, нажмите «Запуск»; для работы с выключенным экраном исключите приложение из оптимизации батареи через его настройки.

Минимальная версия Android: 8.0. APK предназначен для установки напрямую, не для Google Play, и подписан сохранённым личным debug-ключом; приватный ключ находится только в GitHub Actions secret, а не в репозитории.

## Важные ограничения

Верхняя строка состояния Android не показывает цветные статусные значки: цветные кружки находятся в раскрытом уведомлении и приложении. Уведомление показывает до восьми адресов; полный список доступен в приложении. ([Правила Android для уведомлений](https://developer.android.com/design/ui/mobile/guides/home-screen/notifications))

Для постоянной работы с выключенным экраном может потребоваться дополнительное разрешение фоновой работы в настройках производителя. Doze ограничивает сеть и wake lock, поэтому foreground service не даёт универсальной гарантии непрерывности на всех телефонах. ([Документация Doze](https://developer.android.com/training/monitoring-device-state/doze-standby))

После перезагрузки или принудительной остановки запустите монитор вручную. HTTP-задержка и ICMP RTT являются разными измерениями; блокировка ICMP не означает недоступность HTTPS-сервиса.

Полная инструкция, результаты проверок и разбор ошибок исходного HTML находятся в README и каталоге `docs`.
