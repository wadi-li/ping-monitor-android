# Пинг-монитор 1.1.0

Обновление интерфейса нативного Android-монитора. Устанавливается поверх версии 1.0.0 с сохранением адресов и статистики при совпадении подписи.

## Новое

- **Компактный режим:** одна строка на сервер со статусом, средним последних 7 измерений задержки и мини-графиком. «Развернуть список серверов» возвращает полные карточки; режим сохраняется.
- **PNG по нажатию:** компактная строка открывает изображение PNG, которое можно сохранить. Полный график использует последние 50 попыток, ошибки показаны разрывами.
- **Удаление:** отдельная кнопка «Удалить» на каждой развёрнутой карточке с подтверждением.
- **Import / Export:** отдельный пункт в настройках. Загрузка списка, сохранение списка и отчёт со статистикой находятся здесь, а не на главном экране.
- **Список серверов:** CSV с `;` и UTF-8 BOM сохраняет порядок и признаки «Опрашивать»; при импорте они восстанавливаются. TXT и старые отчёты по-прежнему поддерживаются.
- **Три темы:** светлая, тёмная, «Как в системе». Системный режим следует настройке Android, выбор сохраняется; прежняя светлая/тёмная тема не сбрасывается.
- **README:** большая кнопка скачивания APK в самом начале.

Среднее 7 использует последние семь полученных значений из сохранённой истории до 100 попыток. Таймауты пропускаются; если значений меньше семи, используется доступное количество, а при отсутствии значений показано «–». Среднее 10 в полной карточке и отчёте сохранено для совместимости: оно считается по ответам внутри последних десяти попыток.

## Установка и ограничения

Установите `ping-monitor-1.1.0.apk` или его идентичную копию `ping-monitor.apk`. Требуется Android 8.0+; приложение рассчитано на установку APK напрямую, не на Google Play.

Цветные кружки доступны в приложении и раскрытом уведомлении. Верхний значок Android монохромный: круг с галочкой, `!` или крестом. ([Правила Android](https://developer.android.com/design/ui/mobile/guides/home-screen/notifications))

Для выключенного экрана настройте исключение из оптимизации батареи; foreground service не отменяет Doze. После перезагрузки или force-stop нужен ручной запуск; поведение конкретного телефона и многочасовой расход батареи требуют проверки на устройстве пользователя. ([Документация Doze](https://developer.android.com/training/monitoring-device-state/doze-standby))

Сборка, lint и постоянная подпись проверены в [итоговом GitHub Actions](https://github.com/wadi-li/ping-monitor-android/actions/runs/41886158974); ограничения описаны в `docs/TESTING_1.1.0.md` в основной ветке репозитория.
